塑能系[黑暗]

等级：刺客2、黑暗卫士2、牧师2、术士/法师2

法术成分：V、S

施法时间：一个标准动作

距离：个人

目标：自己

持续时间：1分钟/每等级

这个法术在日光中或三级及以上的光明法术影响区域内会被驱散。

识破隐形不能看穿这个法术，但是真实目光可以。

你不能通过此法术获得不死生物生物类型。

法术材料：僵尸的一根手指。

邪灵术 / Vile Death p. 229 · ID 4731↗

咒法系（呼唤）[邪恶]

等级：牧师9、术士/法师9

法术成分：V、S、M、XP

施法时间：1个小时

距离：接触

目标：一个实体不死生物

持续时间：永久（解消）

豁免检定：无

法术抗力：有

大地在你的脚边裂开一道缝隙，你可以隐约听见人们痛苦的惨叫。腐秽的红光从裂缝中放射出来，凝聚为一个半透明的邪魔。它对你露出讥笑；大地闭合后，它转身看向你选作受术者的不死宿主。邪魔与不死生物在颤抖中融合，红光随之消散。

你自九层地狱或者无底深渊中召唤炼狱的精魂，并且将它结附在一个实体不死生物上——限于波达尸、囚魂魔、妖鬼、食尸鬼、魔魂尸、木乃伊、夜影、骷髅、吸血鬼、吸血衍体、尸妖以及僵尸。

结附邪魔会给受术不死生物带来炼狱生物模板（怪物图鉴108）。产生的生物独立于你，可以自行行动；它最初对你的态度是冷漠。

材料成分：一小块硫磺、一块价值至少500金币的鸡血石。

经验值消耗：100 XP。

毒蛇群聚 / Vipergout p. 230 · ID 4735↗

咒法系（召唤）[见说明]

等级：术士/法师3

法术成分：Ｖ，Ｓ，Ｍ

施展时间：一个标准动作

距离：近距（25英尺+5英尺/每2等级）

效果：1d4+3个召唤生物

持续时间：1轮/等级

豁免检定：无

法术抗力：可

当你完成这个法术的时候，你感受到一阵剧烈的反胃。一些东西从你的喉咙涌出，最终你呕出一条条毒蛇。

这个法术召唤1d4+1条天界或炼狱中型毒蛇（MM 280）。它们从你的口中窜出，去攻击你的敌人。

一条被这个法术召唤的天界毒蛇有强酸、寒冷、电击抗力5，法术抗力7以及在一次伤害掷骰上提供+2加值的破邪斩。

一条被这个法术召唤的炼狱毒蛇有强酸、火焰抗力5，法术抗力7以及在一次伤害掷骰上提供+2加值的破善斩。

从你完成这个法术的轮开始，你可以以一个标准动作呕出3条毒蛇或者以一个移动动作呕出1条毒蛇（即，如果你移动以后施展这个法术，你必须到自己的下一回合才可吐出毒蛇；如果你未先移动就施展这个法术，那么你可以在这一轮以自己的移动动作吐出1条毒蛇。）。被呕出的毒蛇会落在你的脚边由你指定的相邻方格中，并在同一轮的你的回合行动，与召唤怪物法术召唤的生物相同。

这些蛇并不是真正存在于你的口中，因此他们不会阻止你呼吸。但是除非你吐完所有被这个法术召唤的蛇，你不能说话，使用需要语言成分的法术，启动需要说话的物品。当法术结束时，所有被召唤的蛇都会消失并且还没有吐出来的蛇也会不见。

当你使用召唤法术召唤善良或者邪恶生物时，这个法术就视为相应的阵营。

施法材料：一块蛇皮

粘滞胶团 / Viscid Glob p. 231 · ID 4751↗

咒法系

等级：术士/法师5

法术成分：V、S、M

施法时间：一个标准动作

距离：中距（100尺+10尺/每等级）

目标：一个生物

持续时间：1小时/等级

豁免检定：反射，通过则无效

法术抗力：可

你念出咒语，抛出一个丝质小球。小球离手之后变成直径5尺的湿黏的灰绿色胶团向目标飞射而去。

当你用粘滞胶团攻击时，你对目标进行远程接触攻击。如果你失误，胶团可能会命中别的生物或者附近的格子（参考投掷武器失手 PH158）。确定失手的方向后，掷1d4来决定胶团落点距目标所在格的格数。

任何被胶团击中的中型或者更小型的生物必须立即做反射豁免以避免立即被粘在那里。被粘住的生物只可以说话或者做只需要心灵的动作（如施展不需要姿势和材料成分的法术）并且只能够以整轮动作进行力量或者逃脱检定（DC为该法术DC）来挣脱。大型或者更大的生物被粘住时，只是不能移动，其他动作则不受影响。

在法术结束，胶团消失之前，胶团都会保持粘性。因此任何碰到胶团的生物（例如想要拉出同伴的生物）必须通过一个反射豁免来避免被粘住。像这样接触而被粘住的生物并不会像完全被击中的粘住地生物那样难以逃脱，因此，挣脱它所要进行的力量或者逃脱检定的DC会减少5。

材料成分：一个蜘蛛丝做的小球
