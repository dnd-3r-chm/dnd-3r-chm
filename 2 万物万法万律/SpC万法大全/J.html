犬牙参差 / Jagged Tooth p. 126 · ID 4669↗

变化系

等级：德鲁伊3、巡林客2

法术成分：言语、姿势

施法时间：标准动作

距离：邻近（25尺+5尺/每2等级）

目标：目标生物的一件造成挥砍或穿刺伤害的天生武器

持续时间：十分钟/每等级

豁免检定：意志过则无效（无害）

法术抗力：可（无害）

当你完成这法术时，你感到你的牙齿突然变得尖锐。施展法术时，一道魔法能量环绕著你指定的目标，目标活动肌肉，欣赏其武器变得更为致命

此法术使一件造成挥砍或穿刺伤害的天生武器的重击威胁范围加倍。此效果不和其他重击威胁范围增加的效果叠加

狼之颚 / Jaws of the Wolf p. 127 · ID 4670↗

变化系

等级：德鲁伊4

法术成分：言语、姿势、器材

施法时间：标准动作

距离：邻近（25尺+5尺/每2等级）

效果：创造一个或更多的座狼

持续时间：1轮/每等级（解消）

豁免检定：无

法术抗力：无

你撒一定数量的木雕在地上，那些木雕马上变成成年座狼，那些座狼的下巴流著唾液对著你的敌人咆哮

你将一些木雕转化成一定数量的座狼（worg，《怪物图鉴》第256页），数量为每2施法者等级一只，这些座狼在你与敌方之间出现，这些狼有自主的意志但服从你的心灵命令。如果那些座狼离开你的法术有效范围或你的法术效果完结时，那些座狼重新变回木雕。座狼死亡时，木雕也会被破坏

器材成分：每创造一只座狼，需要一件座狼木雕（每件25金币）。

欢乐之音 / Joyful Noise p. 127 · ID 4671↗

防护系

等级：吟游诗人1

法术成分：S

施法时间：标准动作

距离：10尺

范围：以你为中心、半径10尺的弥漫范围

持续时间：专注，见说明

豁免检定：不可

法术抗力：无

你在地上跺脚，产生一道噪音波纹，使波纹经过之后被抑制的声音重新响起。

你所造成的音波震动抑制了你所在区域内的任何魔法沉默效果，这个区域随着你的移动而移动，直到你停止集中精力。沉默效果不是被驱散而是被抑制，它将在欢乐之音的有效范围外继续起效。

丛林之伤 / Jungle's Rapture p. 128 · ID 4673↗

变化系

等级：德鲁伊5

法术成分：言语、姿势

施法时间：标准动作

距离：邻近（25尺+5尺/每2等级）

目标：一个非植物的活物

持续时间：永久（解消）

豁免检定：意志过则无效

法术抗力：可

你啐了一口，诅咒一个生物，知道几天后它不是死去，就是变成一株杂草，当你注视著他的时候，对象的身体变得僵硬，然后皮肤表面产生木纹

受此法术影响的活物立即受到1d6点敏捷吸取。对象的身体慢慢硬化，皮肤缓慢地转变成木材，被害者每天额外受到1d6点敏捷吸取。即使损失的敏捷回复，被害者依然每天都会受到1d6点敏捷吸取，直到法术被解除。当被害者的敏捷变成0时，被害者马上变成与原身体同体型的普通植物。除了散发变化系魔法灵光外，它是没有智力、感知和魅力值的普通植物

丛林之伤是一个无法被驱散的诅咒，但可以被破除结界（Break Enchantment），有限祈愿术（Limited Wish），神迹术（Miracle）或是祈愿术（Wish）除去，移除诅咒（Remove Curse）也可以解除它，但只有该移除诅咒的施法者等级等于或高于你施展丛林之伤时的施法者等级才有效。

丛林毁灭者 / Junglerazer p. 127 · ID 4672↗

死灵系

等级：德鲁伊3、术士/法师3

法术成分：言语、姿势、材料

施法时间：标准动作

距离：120尺

范围：120尺线形

持续时间：立即

豁免检定：反射过则减半

法术抗力：可

一道隐形的破坏能量向前安静地划过，立即破坏范围内所有天然植物并留下一道灰烬的痕迹

范围内的精类、虫类、植物、植物生物和动物受到每施法者等级1d10点负能量伤害（最多为10d10）

材料成分：一撮烧焦的植物的灰烬
