海藻之绞 / Kelpstrand p. 128 · ID 4327↗

咒法系（创造）

等级：德鲁伊2

法术成分：言语、姿势、材料

施法时间：标准动作

距离：邻近（25尺+5尺/每2等级）

目标：每3个施法者等级一个生物，任意两个目标相距不超过30尺

持续时间：1轮/每等级

豁免检定：无

法术抗力：无

你伸出手，长长的湿海藻伸出去包围你的敌人

对每个目标分别进行一次远程接触攻击，如果击中的话，你可以立即以自由动作作一个不会被借机攻击的擒抱检定;你在擒抱检定结果上加上施法者等级与感知加值，以此代替通常的力量加值和体型加值。若你成功， 目标会被浓密的海藻缠住，陷入擒抱，每轮目标都可以尝试以擒抱检定或脱逃术检定，对抗海藻的擒抱检定，成功便可脱身。使用此法术时，你自己并不视为处于擒抱中。射出海藻后，你无须采取任何动作来维持效果。

若对象被多个海带捆绑，它必须对每条正在擒抱自己的海藻分别成功进行擒抱检定或脱逃术检定，才能脱身。当你在离海岸300尺以内施展此法术时，你的海带的擒抱检定+4

材料成分：一片干海带

吸血鬼之吻 / Kiss of the Vampire p. 128 · ID 4329↗

死灵系

等级：术士/法师7

法术成分：言语、姿势、材料

施法时间：标准动作

距离：个人

目标：自己

持续时间：一轮/每等级

通过汲取不死的能量，你赋予自身类似吸血鬼的能力。你变得面容枯槁、肤色苍白，双眼散发着野兽般的红光。

你获得伤害减免10/魔法，并且每轮可以以一个标准动作使用下列能力之一：

  • 弱能术（Enervation），以近战接触攻击的形式施展。
  • 吸血鬼之触（Vampiric Touch），以近战接触攻击的形式施展。
  • 魅惑人类（Charm Person）。
  • 气化形体（Gaseous Form）只限自己。

在此法术持续期间，造成伤害系列（inflict）法术会治疗你，而治疗伤害系列（cure）法术则会伤害你。所有法术和效果的目标，你均被视为不死生物。若一次驱散（或斥喝）尝试能成功影响与你生命骰相同的不死生物，你必须进行意志豁免检定（DC 10+驱散者的魅力调整值），否则恐慌（或畏缩）10轮。若该次驱散尝试能摧毁（或命令）与你生命骰相同的不死生物，你必须进行意志豁免检定（DC 15+驱散者的魅力调整值），否则被震慑（或魅惑，如同魅惑怪物）10轮。

你通过此法术创造的任何魅惑效果会在此法术结束时一同结束，但其他所有效果均持续至其正常持续时间结束。

材料成分：一枚价值至少50gp、雕有獠牙利口面孔形象的黑玛瑙。

骑兵突击 / Knight's Move p. 129 · ID 3796↗

变化系（传送）

等级：牧师3、圣武士2

法术成分：言语、姿势、法器

施法时间：一个迅捷动作

距离：5尺/每2等级;见说明

目标：自己

持续时间：立即

你面前的地面仿佛覆盖着棋盘图案，其中某些方格泛着柔和的红光。当你无需步行便移至指定位置时，时间仿佛为你停止。

你可以进行距离有限、移动方式谨慎的传送。此法术使你瞬间移动至多每2施法者等级5尺，但你必须在一个使你能够夹击敌人的方格中结束移动。

解析强者 / Know Greatest Enemy p. 129 · ID 4331↗

预言系

等级：黑暗守卫1、圣武士1

法术成分：言语、法器

施法时间：标准动作

距离：60尺

区域：锥形散发

持续时间：专注，最多为每等级1轮

豁免检定：无

法术抗力：可

你的眼睛发出绿光，然后转变成金色，你对对手作出一次检视，最弱者被淡绿色的光晕勾勒出来，然后依次上升，最强者会被一个翠绿色的光环环绕著

这个法术对范围内的生物作出评估，生物的评估如下表：

CR 实力
4或以下 弱
5-10 中等
11-15 强
16或以上 压倒性

在同一实力类别的生物中，你知道哪个是最强力的，但不知道为什么。例如：一群食人魔（CR2）内，你知道最强的是一个有2级野蛮人等级的食人魔（CR4），但你不知道它较强是因为职业等级、模板（例如半炼狱）还是其他原因

任何3环或更高环阶、能够阻止对生物进行探知（如回避侦测 nondetection）或对区域进行探知（如虚假景象 false vision）的法术，都会阻止本法术评估该生物或该区域内的生物。

辨析敌手 / Know Opponent p. 129 · ID 4332↗

预言系

等级：吟游诗人3、牧师3

法术成分：姿势、法器

施法时间：标准动作

距离：邻近（25尺+5尺/每2等级）

目标：一个生物

持续时间：立即

豁免检定：意志过则无效

法术抗力：可

你的眼睛发出神奇的光芒，法术完成后，你看到发光的字样出现在法术目标上方的空中，按你的意愿描述该生物的长处或短处

你了解到对方的长短处，数量为1+每2个施法者等级1个长处或短处（最多4个），你可以选择去了解长处或短处，或指定两者各占多少项。若目标有多于你能够知道的长短处，你会优先得知其中最强大的项目。例如：目标能够随意使用死亡一指（Finger of Death），并具有音波抗性5,你会先得知死亡一指。

长处包括攻击方式，特殊能力（包括类法术能力Sp或超自然能力Su）.短处包括能量伤害的弱点

例如，一个7级牧师对一个黑装甲武士（blackarmored warrior）使用此法术，并希望得知1个长处及2个短处。而黑装甲武士的豁免检定失败，DM需要告诉该牧师黑装甲武士具有能量吸取能力（长处），害怕阳光以及会被圣徽逼退（短处2个）。牧师于是得出结论为他面临著一个吸血鬼，并取出了木桩。

解析弱点 / Know Vulnerabilities p. 129 · ID 4333↗

预言系

等级：吟游诗人2、牧师3、术士/法师4

法术成分：言语、姿势

施法时间：标准动作

距离：邻近（25尺+5尺/每2等级）

目标：一个生物

持续时间：立即

豁免检定：意志过则无效

法术抗力：可

你的眼睛变红，然后变成金色。当你望向一个生物时，你可以看到一些小符文在他头上出现，每个符文标示一项抗性或弱点：红色表示抗性，绿色表示弱点

你得知目标具有的特殊特性、弱点和抗性。弱点包括任何使其受到高于正常伤害的因素，例如寒冷亚种生物的火焰易伤，或晶体生物对粉碎音波（shatter）的脆弱。抗性包括任何减少或抵消其所受伤害的效果，以及对特定攻击的免疫。本法术也能识别由法术效果赋予的抗性和弱点。

例如，如果你对一个巴洛炎魔（balor）使用，你得知对象会伤害减免15/寒铁且善良，法术抗力28,免疫毒，火焰，和电，并有10点酸抵抗和冰抵抗，而没有什么特别的弱点。
